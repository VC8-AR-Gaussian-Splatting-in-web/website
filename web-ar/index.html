Web & AR Integration

3D Gaussian Splats lassen sich direkt im Browser darstellen — ohne Plugin, ohne App. Wir nutzen dafür Babylon.js, eine WebGL-/WebGPU-Engine, die seit Version 7 Gaussian Splatting nativ unterstützt.

Babylon.js

Babylon.js ist eine quelloffene 3D-Engine, die im Browser über WebGL2 (bzw. WebGPU) rendert. Für unseren Anwendungsfall sind drei Eigenschaften entscheidend:

  • Nativer Gaussian-Splatting-Support — .splat, .ply und das komprimierte .spz werden direkt über den Scene-Loader geladen; kein eigener Shader nötig.
  • WebXR integriert — derselbe Code läuft später als immersive AR-Session (siehe unten).
  • Läuft überall — Desktop, Android-Chrome, iOS-Safari teilen sich eine Codebasis.

Szene aufsetzen

Eine minimale Babylon-Szene braucht eine Engine (gebunden an ein <canvas>), eine Scene und eine Kamera. Für einen Splat-Viewer eignet sich die ArcRotateCamera (Orbit-Steuerung per Maus/Touch):

const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true);

const scene = new BABYLON.Scene(engine);
const camera = new BABYLON.ArcRotateCamera(
  "camera", -Math.PI / 2, Math.PI / 2.2, 6, BABYLON.Vector3.Zero(), scene
);
camera.attachControl(canvas, true);   // Maus-/Touch-Steuerung aktivieren

engine.runRenderLoop(() => scene.render());
window.addEventListener("resize", () => engine.resize());

Splat laden (.spz importieren)

Das von Person B exportierte Modell wird über SceneLoader.ImportMeshAsync geladen. Der passende Loader wird automatisch an der Dateiendung erkannt (.splat, .ply, .spz):

// Voraussetzung: babylonjs.loaders eingebunden (registriert den Splat-Loader)
const result = await BABYLON.SceneLoader.ImportMeshAsync(
  null,                 // alle Meshes
  "models/",            // Wurzelpfad
  "szene.spz",          // Datei (von Person B)
  scene
);

const splat = result.meshes[0];       // GaussianSplattingMesh
splat.position.y = 0;

.spz ist das komprimierte Splat-Format fürs Web (deutlich kleiner als .ply). Es wird ab Babylon.js 7 unterstützt und benötigt das babylonjs.loaders-Paket.

WebXR

WebXR ist die Browser-API für VR und AR. Babylon.js kapselt sie in einem Helper, sodass dieselbe Szene wie oben in eine immersive AR-Session übergehen kann. Drei Bausteine sind nötig:

1. Session starten — wir prüfen erst die Geräteunterstützung und starten dann eine immersive-ar-Session (eigene UI statt Babylon-Default-Button):

const supported = await BABYLON.WebXRSessionManager.IsSessionSupportedAsync("immersive-ar");
const xr = await scene.createDefaultXRExperienceAsync({ disableDefaultUI: true, optionalFeatures: true });
// per Button-Klick:
await xr.baseExperience.enterXRAsync("immersive-ar", "local-floor");

2. Hit-Test — die AR-Session sucht reale Flächen (Boden, Tisch). Ein „Reticle” folgt dem Treffer und zeigt, wo platziert würde:

const hitTest = xr.baseExperience.featuresManager.enableFeature(BABYLON.WebXRHitTest, "latest");
hitTest.onHitTestResultObservable.add((results) => {
  if (results.length) {
    reticle.isVisible = true;
    results[0].transformationMatrix.decompose(undefined, reticle.rotationQuaternion, reticle.position);
  } else {
    reticle.isVisible = false;
  }
});

3. Objekt platzieren — ein Tap setzt das Splat an die aktuelle Reticle-Pose:

scene.onPointerDown = () => {
  if (xr.baseExperience.state === BABYLON.WebXRState.IN_XR && hitTest && splat) {
    splat.setEnabled(true);
    lastHit.transformationMatrix.decompose(undefined, splat.rotationQuaternion, splat.position);
  }
};

Wichtig: WebXR braucht einen sicheren Kontext (HTTPS). Die Live-Seite über GitHub Pages erfüllt das.
